## Directive

In this fictional example, `<team_name>` would obtain a documented public-release review before publishing a generated document.

## Scope

This fictional instruction would apply only to generated documents intended for public release by `<team_name>`.

## Required actions

* [ ] `<team_name>` submits the document and its cited public sources to `<review_role>`.
* [ ] `<review_role>` checks factual claims, links, approval metadata, and public-data safety.
* [ ] `<document_owner>` resolves findings before publication.

## Exceptions

None in this fictional example.

## Verification / completion criteria

The fictional review would be complete when `<review_role>` records the result and all blocking findings are resolved.
