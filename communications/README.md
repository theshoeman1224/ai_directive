# Communications

This directory holds the canonical final approved wording of significant emails, announcements, instructions, rollout messages, and policy-change notifications.

Do not keep a separate file for every draft. Use pull-request and Git history to preserve wording changes. Add the canonical artifact once its wording is approved, with `Status: APPROVED`. Change the status to `SENT` and record `Date Sent` only after it is actually issued.

A communication records what was said. It does not replace the related directive or decision as the authority for policy or worker action.

Use [the communication template](../templates/communication.md). Include public references when they materially support the message. Cite only publishable sources; use `<internal_source_reference>` when a private source must be acknowledged without being exposed.
